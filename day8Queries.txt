Shard a particular collection
1. Enable sharding at the database level
sh.enableSharding("shardingDb")
2. Shard the zipcode collection
Select the shard key
	-- Shard key should be an indexed field in asc order
  
sh.shardCollection("shardingdb.zipcode",{state:1})

sh.splitAt(namespace, query)
Splits a chunk at the shard key value specified by the query.
sh.splitAt("shardingDb.zipcode",{state:"NH"})

sh.splitFind(namespace, query)
Splits the chunk that contains the shard key value specified by the query at the chunk's median point. sh.splitFind() creates two roughly equal chunks. 
sh.splitFind("shardingDb.zipcode",{state:"VT"})

sh.moveChunk(namespace, query, destination)
Moves the chunk that contains the document specified by the query to the destination shard. sh.moveChunk() provides a wrapper around the moveChunk database command.
sh.moveChunk("shardingDb.zipcode",{state:"NY"},"shard1rs")
