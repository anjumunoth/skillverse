db.collectionName.find(predicateCondition, projectionCondition)
projectionCondition : jsonObject -- list of inclusions or exclusions

db.employee.find({},{salary:1});// salary, _id
db.employee.find({},{salary:1,_id:0});// salary

db.employee.find({},{salary:0});// All the fields other than salary will be displayed

db.employee.find({},{salary:0,_id:0});// All the fields other than salary  and _id will be displayed

db.employee.find({},{salary:1,empId:0});// Error that projection cannot have both inclusions and exclusions

Projection with an array :
	-- Rules 
  	-- Predicate condition should be on an array field :
$slice
$
$elemMatch


$:
	-- Return the first element which satisfies the predicate condition on the array
db.zipcode.find(
{loc:{$gt:40}},
{"loc.$":1}
)

$slice:
Specify the number of elements in the array to be projected

db.collName.find({predicateCondition},{$slice:n});// positive number: first n elements; negative number : last n elements; n>size of array -- all elements
db.collName.find({predicateCondition},{$slice:[number,number]});
// $slice:[numberToSkip,numberToReturn ]
	numberToSkip
  	-- positive number : skip from the beginning of array
    -- negative number : skip from the end of array
  numberToReturn -- should be always positive
  
  
[10,20,30]
[ 0, 1 ,2]

$slice:[-1,1]
size of the array : 3-1 = 2; from the 2nd position , display one element:

$slice:[-2,1]
size of the array : 3-2 = 1; from the 1st position , display one element: 20

Return an array with the last 3 elements:
db.student.find({},{marks:{$slice:-3}})

Return an array with the  3 elements after skipping the first element:
db.student.find({},{marks:{$slice:[1,3]}})

Return an array with the  3 elements after skipping the last element:
db.student.find({},{marks:{$slice:[-1,3]}})



$elemMatch:

db.restaurant.find(
{},
{name:1,borough:1}
)
// count of docs : 3772
// projected fields : name, borough,_id

db.restaurant.find(
{},
{name:1,borough:1,_id:0}
)
// count of docs : 3772
// projected fields :name, borough


db.restaurant.find(
{},
{
name:1,borough:1,_id:0,
grades:{$elemMatch:{score:2}}
}
)
// count of docs : 3772
// projected fields :name, borough, first element of grades array which satisfies the condition given as part of elemMatch



compare the foll 2 queries

db.students.find(
{
	marks:{$elemMatch:{$gt:50,$lt:60}}
}
)
// count of docs : docs which have a single mark in the range 50 to 60
// projected fields :all

db.students.find(
{},
{
	marks:{$elemMatch:{$gt:50,$lt:60}}
}
)
// count of docs : all 
// projected fields: marks : one element(single mark in the range 50 to 60) or zero element(no mark in the range 50 to 60) 


Chaining of methods with find()
count()
limit()
sort()
skip()

count()
	-- return the count of docs returned from the find call
  db.collectionName.find(predicateObject,projectionObject).count();
  db.students.find({studentName:/^s/i}).count();// Only count --5
  
limit()
	-- limit the result set to the given number of docs
  db.students.find({studentName:/^s/i}).limit(2);// Only first 2 docs will be displayed
  
skip()
	-- skip some of the elements in the result set:
  -- Negative number will throw an error
  db.students.find({studentName:/^s/i}).skip(2);// Skip first 2 docs and display the rest of the result set will be displayed
  
100 docs : skip the first 5 and get the next 5 
db.zipcode.find({state:"MA"}).skip(5).limit(5)
db.student.find().skip(3).limit(3);// 104,105,106
db.student.find().limit(3).skip(3);// 104,105,106

sort()
	-- sort asc or desc order
db.students.find().sort({studentName:1});//asc 
db.students.find().sort({studentName:-1});//desc 

db.students.find().sort({studentName:1,studentId:1});//both in asc 
db.students.find().sort({studentName:1,studentId:-1});//studentName in asc order and the wherever studentName is same, sort in desc order of studentId

updateMany():
	-- update multiple docs 
		-- matchedCount : 0,1,2,3....count() 
  	-- modifiedCount : 0 or more
  	-- modifiedCount<= matchedCount
    
    
  -- Combinations possible :
  {matchedCount:1, modifiedCount:1,acknowledged:1}
  {matchedCount:1, modifiedCount:0,acknowledged:1}
  {matchedCount:0, modifiedCount:0,acknowledged:1}
  {matchedCount:10, modifiedCount:6,acknowledged:1};// 10 docs which match the find criteria and only 6 docs which are getting updated. the other 4 may already have the updated value
  {matchedCount:6, modifiedCount:6,acknowledged:1}
  
  -- Combinations not possible:
  {matchedCount:5, modifiedCount:7,acknowledged:1}


replaceOne:
	-- 2 params
  	-- findCriteriaObject
    -- replaceDoc
    // replace the entire doc which matches the search criteria with the second param
		//_id remains the same

db.students.updateOne({studentId:102},{$set:{studentId:999,studentName:"Jack",school:"DAV"}});
// change studentId:999, studentName:Jack and school to DAV and keep the other fields intact

db.students.replaceOne({studentId:102},{studentId:999,studentName:"Jack",school:"DAV"})
// change studentId:999, studentName:Jack and school to DAV and remove the other fields

Update part of the doc -- updateOne
Replace the entire doc -- replaceOne 

Deletion of records:
deleteOne()
	-- delete the first doc which matches the filter Criteria
deleteMany()
	-- deletes all the matching Docs
	-- params
  	-- where condition
    
db.students.deleteOne({studentId:103});// delete the first record which matches 103

db.students.deleteOne({}); // delete the first inserted doc
db.students.deleteOne(); // error; needs the first parameter which is mandatory
db.students.deleteMany({studentId:104}); // delete the doc(s)

db.students.deleteMany({studentId:{$gt:300}});// delete doc(s) which matches the criteria

db.students.deleteMany({}); // delete all the docs ; collection will become empty but will exists
