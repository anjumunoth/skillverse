 _id
 	-- Auto generated with a unique value of Object Id data type whenever a document is inserted without an _id field
  -- Insert document can also have an _id . if yes, its not auto generated
  -- By default -- ObjectId
  	-- 12 byte identifier
    		-- 4 byte timestamp
        -- 5 byte machine id and process id
        -- 3 byte incremental counter
  -- Compatible data type : All other than array and regular expression and undefined
  -- Whenever a collection is created, implicitly creates a unique index on the _id field
