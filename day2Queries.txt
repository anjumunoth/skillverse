Regular expression : 
	-- Write a pattern in a string format
  	-- Enclose between the slashes
    -- case sensitive
    
1. Start with s
	/^s/ ;
2.  Start with s/S
	/^s/i
3. Ends with a 
	/a$/
4. Ends with ara
	/ara$/
5. Starts with s and is only 4 characters
/^s.../

3 special wild card expressions
? -- 0 or 1 character (preceeding character)
* -- 0 or more characters(preceeding character)
+ -- 1 or more characters(preceeding character)

/good/
/go?d/ -- gd, god ; Not matching -- good 
/go*d/ -- gd,god, good, goooood
/go+d/ -- god, good, goooood

match digits 
1. 1 digit
/[0-9]/
Matching values : anju0; an1ju; 0anju;
Non matching values: anju01

2. 10 digits
/[0-9]{10}/
Matching values : 1234567890; 77777777777

Why Objects ?
1. In RDBMS -- tables, referential integrity constraint
	-- emp table and projects table
  empId and role -- join the 2 tables
  join -- costly -- avoid
  Mongodb introduced -- embedded objects 
  wherever joins are required, the table to be joined is added as a embedded object in the main table itself
  Limitation : Redundancy of data -- there is some redundancy
  Advantages : All data in one doc -- no joins required, fetch one doc and all details, no syncing is required


Data modelling 
Avoid joins
	-- Embedded objects
  -- Referenced objects
