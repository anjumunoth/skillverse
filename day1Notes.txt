Horizontal scaling
	-- 5 servers 
		-- 4 -- read and 1 will do the write
			-- Write --> sent to all the read servers
			-- write stat -- insert emp 1001 info
				-- sent to all the read servers so that the data becomes consistent -- async process
			-- write successful in write server and in 2 of read servers its complete(Write -- N1, n2,n3 -- read servers have completed)
			-- read select * from emp where empId=1001
			-- Scenario 1 : Read to n3: data can be read
			-- Scenario 2 : Read to n5: has n5 finished syncing -- no data can be read/stale data
			-- Scenario 3 : Read to n2: data can be read
			-- Scenario 4 (After 1 minutes and all the servers have synched): read op for 1001 -- fresh data
